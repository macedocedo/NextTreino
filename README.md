NextTreino

NextTreino é uma aplicação web desenvolvida para auxiliar no acompanhamento e evolução dos treinos, permitindo registrar exercícios, cargas, repetições e o histórico de desempenho de forma organizada e acessível.

O sistema foi criado para ajudar atletas, praticantes de musculação e entusiastas do fitness a monitorarem sua progressão ao longo do tempo, facilitando a análise dos resultados e a definição de novos objetivos.

Principais funcionalidades

✅ Registro de treinos por data

✅ Controle de peso e repetições dos exercícios

✅ Histórico completo de evolução

✅ Organização dos treinos por dia ou sessão

✅ Armazenamento local dos dados

✅ Interface responsiva e fácil de utilizar

✅ Consulta rápida dos registros anteriores

Tecnologias utilizadas
HTML5
CSS3
JavaScript
Local Storage
Objetivo do projeto

O NextTreino foi desenvolvido com o objetivo de aplicar conceitos de desenvolvimento Front-End, gerenciamento de dados e persistência local utilizando JavaScript. O projeto demonstra a criação de uma ferramenta prática para acompanhamento de treinos, oferecendo uma experiência intuitiva para registro e monitoramento da evolução física.
